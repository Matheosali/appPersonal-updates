# appPersonal · actualizaciones

Versiones de la app publicadas automáticamente por la CI del repo privado `Matheosali/appPersonal` (`.github/workflows/publish.yml`). **No editar a mano:** cada publicación reemplaza todo el contenido.

- `<canal>/manifest.json`: la última versión de `main` o `dev`.
- `<canal>/bundles/`: la web compilada, cifrada con la clave de la CI.
- `<canal>/apks/`: el APK firmado, cuando cambia la parte nativa.

Para instalar la app por primera vez: https://matheosali.github.io/appPersonal-updates/
